# Smart ClaimAssist – AI Insurance Assistant

## Project Overview

Smart ClaimAssist is a web-based AI-powered insurance assistance system that helps users choose suitable insurance plans based on their personal information. The application analyzes user inputs such as age, income, family size, and health conditions to recommend appropriate insurance plans.

The system is designed to simplify the insurance selection process and provide quick guidance for users who are unsure which policy best suits their needs.

---

## Features

* Insurance plan recommendations based on user profile
* Premium estimation support
* Simple and interactive user interface
* AI-assisted guidance for insurance-related queries
* Easy navigation and responsive design

---

## Technologies Used

The project is developed using the following technologies:

* **React** – Frontend framework
* **TypeScript** – Type-safe JavaScript development
* **Vite** – Fast development build tool
* **Tailwind CSS** – Styling and responsive UI design

## Installation and Setup

Follow these steps to run the project locally:

### 1. Clone the Repository

```
git clone <repository-url>
```

### 2. Navigate to the Project Folder

```
cd your-plan-advisor-main
```

### 3. Install Dependencies

```
npm install
```

### 4. Run the Development Server

```
npm run dev
```

After running the command, open the browser and visit:

```
http://localhost:5173
```

## How the System Works

1. The user opens the Smart ClaimAssist web application.
2. The user enters personal details such as age, income, family size, and health conditions.
3. The system analyzes the information using predefined logic.
4. Based on the analysis, suitable insurance plans are recommended.
5. Users can explore and compare different plan suggestions.
